# КАДР — студия постов для соцсетей

Веб-приложение генерирует готовые посты для Telegram, YouTube и Instagram через Gemini: заголовок, текст, призыв к действию, хэштеги и промпт для картинки.

## Возможности

- Выбор площадки и несколько вариантов на выбор
- Потоковый вывод текста (SSE)
- Перегенерация всех постов или одного варианта
- История в браузере и копирование в один клик
- Отдельное поле с промптом для генерации изображения к посту

## Запуск

1. Скопируйте `.env.example` в `.env` и вставьте ключ [Gemini API](https://aistudio.google.com/apikey):

```
GEMINI_API_KEY=ваш_ключ
GEMINI_MODEL=gemini-3.5-flash-lite
PORT=3001
```

2. Установите зависимости и запустите студию:

```
npm install
npm run dev
```

Откройте [http://localhost:5173](http://localhost:5173). Ключ читается только с сервера из `.env`. После изменения `.env` сервер перезапускается сам.
